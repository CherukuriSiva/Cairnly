The AI era makes starting easier (tools help you learn faster) and harder (there's more to learn). This roadmap cuts through the noise: here is the minimum viable foundation that leads to real jobs and real projects.

## Months 1–2: Programming Fundamentals (8 weeks)
- One language well — Python or JavaScript, not both.
- Variables, functions, loops, data structures, reading errors, and debugging.
- Build tiny things: a calculator, a text game, a script that does something useful.
- Don't move on until you can build something from scratch without a tutorial.

## Months 3–4: Web + AI Literacy (8 weeks)
- How the web works: HTTP, client/server, what a request and a response are.
- Build a basic web page that calls an API.
- Use an LLM API (OpenAI or Anthropic) in a project.
- Understand what tokens, embeddings, and RAG mean — not deeply, just enough to know what they are.

## Months 5–6: First Real Project (8 weeks)
- Build one project you'd be proud to show: a web app with a backend, some AI feature (even just a chatbot), deployed to the internet.
- This is your interview story.
- It doesn't need to be impressive — it needs to be real.

## Skill priorities

**Now**

- One language fluently (don't split focus)
- Building something real every week
- Reading documentation and debugging independently
- Git basics

**Soon**

- Web fundamentals (HTTP, APIs, databases)
- LLM API basics
- Deploying a project

**Later**

- Algorithms and data structures (important but not first)
- Advanced AI
- System design

**Ignore for now**

- Learning 5 languages before mastering 1
- Collecting certificates
- Following every tutorial without building
- Comparing your progress to social media highlights
