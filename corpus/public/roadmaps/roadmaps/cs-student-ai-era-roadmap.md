This roadmap is for CS students in their 1st–3rd year who want to graduate with a strong AI+engineering profile. The goal is not to learn everything — it is to learn the things that compound.

## Year 1: Foundations That Don't Expire (12 months)
- CS fundamentals: data structures and algorithms — enough for coding rounds, not to the exclusion of everything else.
- One programming language mastered: Python or JavaScript, not a shallow tour of five.
- Version control and a building habit: commit often, push to GitHub, ship small things weekly.
- First side project: small, finished, and yours — proof you can take an idea to working code.

## Year 2: AI + Full-Stack (12 months)
- RAG basics: chunking, embeddings, retrieval — enough to build a working document Q&A.
- LLM API usage: prompting, streaming, cost, integrating a model into a real app.
- One full-stack project: front end + back end + deployed to the internet.
- DSA practice: consistent and steady, not frantic cramming.
- Contribute to open source or build in public: visible work that compounds your reputation.

## Year 3: Specialize + Ship (12 months)
- Pick a direction: AI engineering or full-stack — go deep on one.
- Build one substantial portfolio project: the centerpiece of your applications.
- Placement and interview prep: company-targeted, not generic grinding.
- Resume and LinkedIn polished: clear, project-led, and recruiter-readable.

## Final Semester: Placement Mode (3–6 months)
- Mock interviews: coding and behavioral, with real feedback.
- Company research: know what each target actually hires for.
- Competitive programming only if required by your target companies — otherwise skip it.
- Referrals and networking: the highest-leverage activity in the final stretch.

## Skill priorities

**Now**

- DSA fundamentals
- One programming language fluently
- Git and public code
- Building side projects

**Soon**

- RAG and LLM APIs
- Full-stack web (front + back + deploy)
- System design basics

**Later**

- Agents and multi-agent systems
- Fine-tuning
- Cloud certifications

**Ignore for now**

- Competitive programming as primary strategy unless targeting those companies
- Tutorial certificates
- Learning every new framework
- Social media performance instead of actual building
