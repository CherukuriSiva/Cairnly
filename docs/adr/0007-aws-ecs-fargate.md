# ADR 0007: Deploy to AWS on ECS Fargate with RDS, via Terraform and GitHub OIDC

Status: accepted (M2), not yet applied. Amended by
[ADR 0013](0013-models-on-a-modal-gpu.md): the CPU Ollama task and the Claude API are gone;
the models run on a Modal GPU. Superseded as the default deploy by
[ADR 0017](0017-free-tier-production.md); kept as the documented alternative.

## Context

The target is a deployable product a small team can run without a platform team: few moving
parts, no servers to patch, secrets never in code or CI.

## Decision

ECS Fargate (api, web, CPU Ollama for embeddings) behind one ALB with path routing, RDS
Postgres 17 + pgvector, Secrets Manager for the database password (generated by RDS) and the
Claude key. Terraform state in S3 with native locking. GitHub Actions deploys through an OIDC
role, so no AWS access keys exist anywhere. A Helm chart covers Kubernetes customers.

## Consequences

- About $120/month idle; the NAT gateway is the biggest single line.
- Answers default to the Claude API in the cloud: CPU Fargate cannot run an 8B model at usable
  speed, and a GPU instance costs more than API usage at demo scale.
- Fargate over EKS: less to operate; customers already on Kubernetes use the Helm chart.
