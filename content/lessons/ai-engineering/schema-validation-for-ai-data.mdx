<Body>
## JSONL: one record per line

AI datasets are almost always **JSONL** — one JSON object per line. It streams (you don't load the whole file into memory), it appends cleanly, and a single corrupt line doesn't break the rest.

## The schema gate

Define the exact shape every record must have, and validate at the boundary — when you write and when you read. A typed model gives you free validation and clear errors:

```python
from pydantic import BaseModel, field_validator

class QARecord(BaseModel):
    instruction: str
    input: str
    output: str

    @field_validator("instruction", "output")
    @classmethod
    def non_empty(cls, v: str) -> str:
        if not v.strip():
            raise ValueError("must be non-empty")
        return v
```

Now an invalid record raises at ingestion with a message like `output: must be non-empty`, instead of poisoning training.

## Atomic writes

If your write job crashes halfway, you must not be left with a truncated dataset that *looks* valid. Write to a temp file, then `os.replace` it into place — `replace` is atomic on the same filesystem, so readers either see the old file or the complete new one, never a half-written mess.
</Body>

<Code>
```python
import json, os, tempfile
from pathlib import Path

def load_records(path: str) -> list[dict]:
    """Stream a JSONL file, validating each line against the schema."""
    records = []
    with open(path) as f:
        for lineno, line in enumerate(f, 1):
            line = line.strip()
            if not line:
                continue
            try:
                records.append(QARecord(**json.loads(line)).model_dump())
            except Exception as e:
                raise ValueError(f"{path}:{lineno} invalid record: {e}")
    return records

def write_records_atomic(path: str, records: list[QARecord]) -> None:
    """Write JSONL atomically: temp file + os.replace."""
    p = Path(path)
    fd, tmp = tempfile.mkstemp(dir=p.parent, suffix=".tmp")
    with os.fdopen(fd, "w") as f:
        for r in records:
            f.write(r.model_dump_json() + "\n")
    os.replace(tmp, p)   # atomic on the same filesystem
```
</Code>

<CommonMistakes>
- **Validating only on read, not on write** — garbage gets persisted and bites you later
- **Loading the whole file into memory** — JSONL is meant to stream line by line
- **Non-atomic writes** — a crash leaves a truncated file that passes a naive check
- **Swallowing validation errors** — log and re-raise with the line number, don't `continue` silently
- **Schema drift** — changing fields without versioning makes old runs irreproducible
</CommonMistakes>
