<Body>
## A token is a chunk, not a word

Models read **tokens** — sub-word chunks. "tokenization" might be 3 tokens; a common word like "the" is 1. A rough rule for English is ~4 characters per token, or ~0.75 words per token, but you should never guess in production — you should count.

## The context window is a shared budget

The context window (e.g. 8K, 128K, 1M tokens) is the **total** the model can hold at once: system prompt + conversation history + retrieved context + the answer it generates. They all draw from the same pool. Stuff 120K tokens of context into a 128K model and you've left almost no room for the answer.

## Counting tokens before you spend

```python
import tiktoken

def count_tokens(text: str, model_name: str = "gpt-4-turbo-preview") -> int:
    try:
        encoding = tiktoken.encoding_for_model(model_name)
    except KeyError:
        encoding = tiktoken.get_encoding("cl100k_base")
    return len(encoding.encode(text))
```

## Cost is just two multiplications

Input and output tokens are usually priced **differently** (output is pricier). Cost = `input_tokens × input_rate + output_tokens × output_rate`. Track it per request and you'll never be surprised by the invoice.
