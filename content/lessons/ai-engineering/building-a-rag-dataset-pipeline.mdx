<Body>
## Stages, in order, each doing one job

The pipeline is a sequence where each stage's output feeds the next. Order matters: filter *before* you spend LLM calls normalizing; dedup *before* splitting so duplicates can't straddle train/test; run a **second** quality pass *after* synthesis to catch bad LLM output.

## Checkpoints make it resumable

The expensive stages (LLM normalization, synthesis) must survive a crash. Persist a checkpoint of completed IDs after each batch; on restart, skip what's already done. A long pipeline you can't resume is a pipeline you'll never finish re-running.

## Validate at every write boundary

Every file write goes through a schema gate: validate each record against a Pydantic model, and a single bad record raises *before* the file is touched (atomic temp-file + rename). The dataset can never be left half-written or schema-invalid.

## Stratified, reproducible splits

Split *by kind* (QA / refusal / multi-turn) with a fixed seed so each split has the right mix and the result is reproducible. Dedup first — otherwise a near-duplicate in train leaks into test.

## Assertions turn silent rot into a hard failure

End with dataset-level checks: total size ≥ a floor, refusal fraction ≥ a threshold. If synthesis silently produced too few refusals, the pipeline *fails* instead of shipping a skewed dataset. Emit a stats "dataset card" so the artifact is auditable.
</Body>

```python
def run_pipeline(squad_paths, skip_synthesis=False) -> dict:
    checkpoint = load_checkpoint()                       # resumable

    qa, passages = ingest_all_sources(squad_paths)       # 1. ingest
    qa, rejected = filter_on_topic(qa)                   # 2. on-topic
    qa, _ = quality_filter(qa)                           # 3. quality (pass 1)

    curated = [r for r in qa if r["article_id"] == "curated_v1"]
    qa, n_dupes = dedupe_records(curated + [r for r in qa if r not in curated])  # 4. dedup, curated-first

    if not skip_synthesis:
        normalize_records_batch(qa, checkpoint, ...)     # 5. normalize (checkpointed)
        refusals = synthesize_refusals(...)              # 6a. synth refusals
        multiturn = synthesize_multiturn(...)            # 6b. synth multi-turn
        qa = qa + refusals + multiturn

    qa, _ = quality_filter(qa)                           # 7. quality (pass 2, post-synthesis)
    qa = assign_global_ids(qa)                           # 8. IDs
    qa = assign_splits(qa, seed=42)                      # 9. stratified split

    write_validated_jsonl(qa, TRAINING_FILE, TrainingRecord)  # 10. schema gate + atomic
    _build_test_sets(qa, TEST_SETS_DIR)
    stats = compute_stats(qa)

    if stats["total"] < 3500:                            # 11. assertions
        raise AssertionError(f"only {stats['total']} records — need >=3500")
    if not skip_synthesis and stats["refusal_fraction"] < 0.10:
        raise AssertionError(f"refusals {stats['refusal_fraction']:.1%} — need >=10%")
    return stats
```

<CommonMistakes>
- **Synthesizing before filtering** — you pay LLM calls to normalize junk you'll drop
- **Dedup after splitting** — near-duplicates leak across train/test
- **One quality pass only** — synthesis can emit bad records; filter again after
- **No checkpoints** — a crash forces a full, expensive re-run
- **Writing without a schema gate** — a malformed record poisons training silently
- **No end assertions** — a skewed dataset ships unnoticed
</CommonMistakes>
