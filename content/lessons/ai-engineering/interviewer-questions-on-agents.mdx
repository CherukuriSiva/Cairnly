<Body>
## The question bank

**"Walk me through the agent loop."**
ReAct: Thought → Action → PAUSE → Observation, repeating until Answer. The controller executes tools, not the model.

**"How does the agent call a tool?"**
It emits a structured `Action: <tool>: <input>`. My controller parses it, looks the tool up in a registry, executes it inside a try/except, and feeds the result back as an Observation.

**"How do you stop it looping forever?"**
A hard max-iterations cap that raises a clear error. I also track cost per run as a second backstop.

**"How does it remember earlier steps?"**
Short-term memory is the message history of thoughts, actions, and observations. I keep it in budget with a rolling window that pins the original task, or summarize older turns.

**"How do you reduce hallucination in an agent?"**
A reflection pass that validates the final answer against the observations the agent actually collected — grounded in gathered facts, not world knowledge.

**"When is an agent the WRONG choice?"** *(the trap)*
When a single prompt or a fixed pipeline would do. Agents add latency, cost, and failure modes; I only use one when the task needs tools or genuinely dependent multi-step reasoning.

**"How do you make tool use safe?"**
The registry is the barrier: the model can only call vetted, named tools; I apply least privilege and never expose a dangerous tool "just in case."

Q: "How do you stop the agent looping forever?"
A: "I cap iterations [claim]. The loop raises MaxIterationsReached past the
   limit, and I track per-run cost as a backstop [mechanism]. In my project
   I set the cap to 8 after seeing most tasks finish in 3-4 steps [decision]."

Use this shape for every answer: a one-line claim, the mechanism that backs

<CommonMistakes>
- **Over-selling agents** — failing the "when is it wrong?" trap signals inexperience
- **Vague loop descriptions** — name Thought/Action/Observation explicitly
- **No concrete numbers** — "I capped iterations" is weaker than "I capped at 8 after profiling"
- **Confusing short-term and long-term memory** — keep them distinct
- **Forgetting safety** — tool registry as barrier + least privilege should come up unprompted
</CommonMistakes>
