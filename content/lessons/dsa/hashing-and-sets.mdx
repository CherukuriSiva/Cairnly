## Hash map vs. hash set

- **Hash map** (`dict` in Python): stores key-value pairs. Use when you need to associate data with each key (index, count, last-seen position).
- **Hash set** (`set` in Python): stores only keys. Use when you only need existence checks.

Both give average O(1) for insert, delete, and lookup.

## The complement-lookup pattern

Two Sum is the canonical example: instead of checking every pair, store seen values and look up the complement.

```python
def two_sum(nums, target):
    seen = {}  # value -> index
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:
            return [seen[complement], i]
        seen[num] = i
    return []
```

**Time:** O(n). **Space:** O(n).

## Group Anagrams

Group strings by their sorted character signature.

```python
from collections import defaultdict

def group_anagrams(strs):
    groups = defaultdict(list)
    for s in strs:
        key = tuple(sorted(s))   # anagrams share the same sorted form
        groups[key].append(s)
    return list(groups.values())

# group_anagrams(["eat","tea","tan","ate","nat","bat"])
# -> [["eat","tea","ate"], ["tan","nat"], ["bat"]]
```

**Time:** O(n * k log k) where k is the max string length.

## Longest Consecutive Sequence

Find the length of the longest consecutive element sequence in an unsorted array, in O(n) time.

```python
def longest_consecutive(nums):
    num_set = set(nums)
    best = 0
    for n in num_set:
        if n - 1 not in num_set:   # only start counting from sequence starts
            length = 1
            while n + length in num_set:
                length += 1
            best = max(best, length)
    return best

# longest_consecutive([100, 4, 200, 1, 3, 2]) -> 4  (sequence: 1,2,3,4)
```

The trick: only begin counting from numbers that have no left neighbor (`n - 1 not in set`). This ensures each element is visited at most twice total.

**Time:** O(n). **Space:** O(n).

## When to use hashing

| Signal | Structure |
|---|---|
| "Find if X exists" or "find complement" | Hash set or hash map |
| "Count occurrences" | Hash map (Counter) |
| "Group by property" | Hash map with computed key |
| "Find duplicates" | Hash set |
| "O(1) lookup needed to avoid O(n^2)" | Hash set or hash map |
