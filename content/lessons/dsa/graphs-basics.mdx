## Graph DFS

```python
def dfs(graph, start):
    visited = set()
    def explore(node):
        visited.add(node)
        for neighbor in graph[node]:
            if neighbor not in visited:
                explore(neighbor)
    explore(start)
    return visited
```

## Graph BFS

```python
from collections import deque

def bfs(graph, start):
    visited = {start}
    queue = deque([start])
    while queue:
        node = queue.popleft()
        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
    return visited
```

**Critical:** Add to `visited` when enqueuing, not when dequeuing. This prevents duplicate entries in the queue.

## Walkthrough: Number of Islands (LC 200)

A grid of '1's (land) and '0's (water). Count connected components.

```python
def num_islands(grid):
    if not grid:
        return 0
    rows, cols = len(grid), len(grid[0])
    count = 0

    def dfs(r, c):
        if r < 0 or r >= rows or c < 0 or c >= cols or grid[r][c] != '1':
            return
        grid[r][c] = '0'  # mark visited by sinking the island
        dfs(r+1, c)
        dfs(r-1, c)
        dfs(r, c+1)
        dfs(r, c-1)

    for r in range(rows):
        for c in range(cols):
            if grid[r][c] == '1':
                count += 1
                dfs(r, c)
    return count
```

**Time:** O(rows * cols). **Space:** O(rows * cols) worst case for the call stack.

## Walkthrough: Course Schedule (LC 207) - Topological Sort

Detect if you can finish all courses given prerequisites. This is cycle detection in a directed graph.

```python
def can_finish(num_courses, prerequisites):
    graph = defaultdict(list)
    in_degree = [0] * num_courses
    for course, prereq in prerequisites:
        graph[prereq].append(course)
        in_degree[course] += 1

    # Start with courses that have no prerequisites
    queue = deque([i for i in range(num_courses) if in_degree[i] == 0])
    taken = 0

    while queue:
        course = queue.popleft()
        taken += 1
        for next_course in graph[course]:
            in_degree[next_course] -= 1
            if in_degree[next_course] == 0:
                queue.append(next_course)

    return taken == num_courses  # if not, there's a cycle
```

**Time:** O(V + E). **Space:** O(V + E).

## Walkthrough: Clone Graph (LC 133)

Deep copy a graph. Use a hash map to track already-cloned nodes to handle cycles.

```python
def clone_graph(node):
    if not node:
        return None
    cloned = {}

    def dfs(n):
        if n in cloned:
            return cloned[n]
        copy = Node(n.val)
        cloned[n] = copy
        for neighbor in n.neighbors:
            copy.neighbors.append(dfs(neighbor))
        return copy

    return dfs(node)
```

## BFS vs. DFS for graphs

| Scenario | Best choice | Why |
|---|---|---|
| Shortest path (unweighted) | BFS | BFS explores level by level |
| Connected components | Either | Both visit all reachable nodes |
| Cycle detection (directed) | Topological sort (BFS) or DFS with coloring | Kahn's algorithm or three-color DFS |
| Topological ordering | BFS (Kahn's) or DFS (reverse postorder) | Both work; Kahn's is more intuitive |
| Path existence | DFS | Simpler to implement recursively |
</Body>

<CommonMistakes>
- **Forgetting the visited set**: Without it, you'll loop forever in graphs with cycles. For grid problems, marking cells in-place works as a visited set.
- **Adding to visited when dequeuing instead of enqueuing**: In BFS, mark a node as visited when you add it to the queue, not when you remove it. Otherwise the same node can be added multiple times.
- **Treating undirected graphs as directed**: If the problem says "undirected," add edges in both directions when building the adjacency list.
- **Stack overflow on large grids**: Recursive DFS on a 300x300 grid can exceed Python's recursion limit. Switch to iterative DFS with an explicit stack or use BFS.
</CommonMistakes>

<InterviewExplanation>
"For graph problems I first identify the type: connected components, shortest path, or dependency ordering. For connected components like Number of Islands, I use DFS to flood-fill each component. For shortest path in an unweighted graph, I use BFS since it explores nodes level by level. For dependency problems like Course Schedule, I use Kahn's algorithm: compute in-degrees, start from nodes with in-degree zero, and process the graph layer by layer. If I can process all nodes, there's no cycle."
</InterviewExplanation>
